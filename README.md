# SerenKeep downloads

SerenKeep is a home server for your PC.

## Download

The current release is **SerenKeep 0.8.1**, a signed Windows installer.

- **File:** [`SerenKeep-Setup-0.8.1.exe`](https://github.com/trorie/ambient-desktop-releases/releases/download/v0.8.1/SerenKeep-Setup-0.8.1.exe)
- **Release page:** https://github.com/trorie/ambient-desktop-releases/releases/tag/v0.8.1
- **SHA256:** `ab46818039e27b20500991c8df6ad94d3de9df5e03954e13f0bbf7cc1c618a55`
- `SHA256SUMS.txt` is attached to the release.

### Check the file

In PowerShell, in the folder where you saved the installer:

```powershell
Get-FileHash .\SerenKeep-Setup-0.8.1.exe -Algorithm SHA256
```

The hash shown should match the SHA256 above.

### Install

When Windows asks to run the installer, check that the publisher shows **Future Maven LLC**. The release page lists what is new and what is still coming.
